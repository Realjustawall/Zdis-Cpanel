# نتیجهٔ آزمون نسخهٔ 0.2.0-preview

- محیط واقعی آزمون: PHP 8.3.6، MariaDB 10.11.14 و Chromium 153؛ دیتابیس و حساب‌ها جدا و آزمایشی.
- ۱۰۷ درخواست/بررسی HTTP/API پایه موفق؛ ورود/CSRF، گروه و دعوت و کانال خصوصی، پیام، clientId، امضای E2EE، فایل/Range/resumable، دوستی، اعلان، رأی، signaling، ابطال دسترسی و audit.
- ۸۶ درخواست/بررسی HTTP/API تکمیلی موفق؛ تقدم مجوز نقش/عضو، جلوگیری از ارتقای غیرمجاز نقش، انجمن خصوصی و قفل، ناشناسی نظرسنجی، scope و ابطال API key، OAuth redirect و replay code، bot install/command/incoming/uninstall، تعارض revision تنظیم ربات، daily/transfer، self role، ticket خصوصی و بسته‌شده، RSVP و boost.
- تست وب‌هوک یک HTTP request واقعی از PHP/cURL به گیرندهٔ آزمایشی محلی فرستاد و امضای HMAC را بررسی کرد؛ allow-local فقط در config تست فعال بود. سرویس اینترنتی تولید یا رقابت چند worker تست نشده است.
- آزمون مرورگر با UI اصلی: ورود، گروه/کانال، ارسال پیام و ماندگاری نشست؛ دو حساب در browser context مستقل DM را رمزگذاری و رمزگشایی کردند؛ تماس با دوربین/میکروفن مصنوعی زنگ خورد و پاسخ و RTP دریافت شد. تماس واقعی، screen share و NAT/TURN بیرونی تأیید نشده‌اند.
- صفحهٔ ورود انگلیسی/فارسی در دسکتاپ و فارسی در موبایل با مرجع مقایسه شد. نتیجهٔ دقیق در visual-comparison.json است. همهٔ صفحات یا بنر ربات مقایسهٔ تصویری نشده‌اند.
- فایل‌های frontend source با نسخهٔ اصلی مقایسه شدند؛ فقط realtime.ts تغییر import دارد و یک transport جدید افزوده شده است. CSS خروجی با بیلد مرجع یکسان است.
- فایل‌های PHP بررسی نحوی شده‌اند؛ گزارش دقیق و تعداد در php-lint.json.

عدد ۱۹۳ جمع درخواست‌های بررسی‌شدهٔ دو مجموعه است، نه تعداد ویژگی‌های کامل یا آزمون پوشش همهٔ پروژه. آزمون‌های قدیمی در نسخهٔ جدید دوباره اجرا شدند. توصیف کامل کاستی‌ها در PORTING-STATUS.md آمده است. استقرار روی cPanel واقعی، MySQL 8 مستقل، بار/HA، ارتقای دیتابیس، مهاجرت و قابلیت‌های منتقل‌نشده تأیید نشده‌اند.

تصاویر مرورگر در بسته نیستند. JSONهای validation شواهد اجرا هستند. این گزارش تأیید نسخهٔ کامل یا آمادهٔ تولید نیست.
