# وضعیت انتقال ZDIS به PHP/MySQL

مخزن مرجع: https://github.com/Realjustawall/zdis
Commit: 655b0afed3dc93cda9eebd189bd00c6fcf53f5e7
نسخهٔ پورت: 0.3.0-preview

این بسته هنوز انتقال کامل تمام قابلیت‌های نسخهٔ اصلی نیست. رابط اصلی و همهٔ صفحات آن حفظ شده‌اند؛ باقی‌ماندن یک کنترل در رابط به معنی آماده‌بودن بک‌اند آن نیست. مسیرهای منتقل‌نشده خطای صریح 501 می‌دهند. این نسخه برای بررسی و نصب آزمایشی روی دیتابیس تازه است.

## بخش‌های دارای پیاده‌سازی

- نصب‌کنندهٔ اولین بازدید با فرم دیتابیس، تست اتصال واقعی، ساخت خودکار تنظیمات/کلید امنیتی و حساب مدیر و قفل نصب مجدد؛ مدیریت رمز مدیر و کاربران.
- PHP و PDO/MySQL بدون نیاز به Node.js هنگام اجرای سایت؛ فایل‌های خصوصی خارج از Document Root، راه‌اندازی از CLI یا نصب‌کنندهٔ تحت وب، Cron.
- احراز هویت با کوکی HttpOnly، CSRF و Origin، محدودیت درخواست، TOTP، کدهای بازیابی یک‌بارمصرف و ابطال نشست‌ها.
- گروه، کانال، دسته‌بندی، دعوت، عضویت، پروفایل، آواتار، دوست/بلاک، DM و گروه DM، اعلان داخل برنامه و تنظیمات.
- پیام، پاسخ، ویرایش/حذف، واکنش، پین، ذخیره‌شده‌ها، جست‌وجو، خوانده‌نشده، زمان‌بندی و انقضا، جلوگیری از تکرار با clientId.
- رمزنگاری DM در همان کد مرورگر اصلی و بررسی امضای ECDSA در PHP. کلید خصوصی دستگاه طبق الگوی bootstrap پروژه با app_key سرور محافظت می‌شود؛ این طراحی zero-knowledge نیست.
- نقش‌های گروه، مجوزهای everyone و نقش، سلسله‌مراتب، منع ارتقای نقش عضویت توسط مدیر تفویض‌شده، مجوزهای عضو/نقش/کانال/دسته، sync، timeout و الزام 2FA برای مدیریت گروه. نقش‌های سفارشی پلتفرم هنوز CRUD کامل ندارند.
- انجمن خصوصی با کنترل دسترسی روی ریشه و پاسخ، فهرست و رویدادها و فایل، اعضای thread، قفل/آرشیو؛ نظرسنجی، ناشناسی رأی‌دهنده، تحلیل ویژهٔ سازنده و حالت آزمون؛ follow/publish اعلان‌ها.
- ربات‌های داخلی: تنظیمات با revision، پیام خوش‌آمد/خداحافظی و auto role، تولید PNG اولیه با GD، قواعد ضداسپم، اقدام‌های مدیریت و پرونده‌ها، protection، XP/level و پاداش نقش، credits/daily/transfer/reputation، self roles، ticket خصوصی و transcript، embed، temporary voice/invite، starboard و anti-raid. پوشش آزمون این زیرسیستم کامل نیست؛ بنر فعلی تطبیق تصویری کامل با Sharp نسخهٔ اصلی ندارد و فرمان‌های متنی داخلی هنوز منتقل نشده‌اند.
- API key با نمایش یک‌بارهٔ secret، hash، scope، انقضا و ابطال؛ OAuth app با redirect URI ثبت‌شده و code یک‌بارمصرف؛ bot account/token و نصب/حذف، slash command و incoming webhook.
- وب‌هوک خروجی با HMAC، جلوگیری از مقصد خصوصی/محلی در تنظیم تولید، pin کردن DNS، بازبینی مجوز هنگام تحویل، صف پایدار در MySQL، lease و حداکثر ۵ تلاش با تأخیر. external receiver باید delivery ID را برای جلوگیری از اثر تکراری ذخیره کند؛ تحویل exactly-once تضمین نمی‌شود.
- sync و export/import پیام‌های متنی؛ ابزار مهاجرت دیتابیس اصلی آماده نیست و import عمومی جایگزین مهاجرت کامل نیست.
- رویدادهای اجتماع و RSVP، boost، tier و subscription به صورت اطلاعات برنامه؛ پرداخت مالی متصل نشده است. insights و automod اولیه.
- آپلود محلی معمولی/قطعه‌ای، دریافت دارای مجوز و HTTP Range؛ کنترل header فایل رمز‌شده و فایل صوت؛ دسترسی فایل آیکن نقش.
- صوت/تصویر WebRTC mesh با سقف ۸ نفر، زنگ و signaling و حالت میوت/ویدئو. تست رسانهٔ مصنوعی مرورگر موفق است؛ سرویس SFU منتقل نشده است.
- مدیریت اصلی کاربران، نشست، دسترسی حساب، تنظیمات، آمار و audit عادی.

| امنیت و عملیات | RBAC کامل مدیران پلتفرم، audit تغییرناپذیر/verify، backup/restore، appeal و review، DLP، حذف آبشاری/انتقال مالکیت حساب |

## رابط و حدود ادعای تطابق

سورس صفحات، کامپوننت‌ها، CSS، زبان‌ها و دارایی‌های اصلی بازطراحی نشده‌اند. تنها import فایل realtime.ts به انتقال PHP تغییر کرده و cpanelRealtime.ts افزوده شده است؛ فایل‌های dist خروجی بیلد هستند. تطبیق تصویری صفحهٔ ورود انجام شده، نه تمام صفحات و تمام حالت‌ها. backend polling حدود ۰٫۹ ثانیه دارد و بعضی فهرست‌ها در حافظه فیلتر می‌شوند؛ این نسخه تأیید کارایی نصب بزرگ نیست.

TEST-RESULTS.md و validation فقط نتایج آزمون‌های واقعاً اجراشده را ثبت می‌کنند. موفق‌بودن این آزمون‌ها به معنی کامل‌بودن پروژه نیست.
